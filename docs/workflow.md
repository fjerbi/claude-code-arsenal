# Workflow

1. Understand the request and scope.
2. Search for the minimum relevant code.
3. Inspect only the specific files needed.
4. Identify the root cause or requirement.
5. Decide whether the work can be partitioned safely into parallel tracks.
6. Assign work to the smallest relevant specialist agents.
7. Apply the smallest correct change in dependency order.
8. Validate each affected branch with focused evidence.
9. Reconcile outputs before finalizing the result.
10. Stop when the evidence confirms the result.

Keep this workflow short, disciplined, and dependency-aware.
