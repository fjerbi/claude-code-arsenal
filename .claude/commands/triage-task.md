# Triage Task

Goal: reduce ambiguity before making a change.

Steps:
1. Restate the requested outcome in one sentence.
2. Identify the relevant files, modules, or systems.
3. Decide whether the task is a bug fix, feature, refactor, or validation exercise.
4. List constraints, risks, and unknowns.
5. Choose the smallest safe next action.

Guardrails:
- Do not broaden scope without evidence.
- Do not start editing before the task is understood.
- If the requirement is unclear, state the uncertainty and ask only if needed.
