# Next.js 15 (React 19 for App Router; Pages Router may stay on React 18)

Source: nextjs.org/blog/next-15 (15.0 release notes). Verified 2026-10-05. For APIs added in later 15.x minors, check `node_modules/next/*.d.ts`.

## Requirements
- Node.js ≥ 18.18.
- `next.config.ts` is supported (`import type { NextConfig } from 'next'`).

## Request APIs are async — always await
- `params` (in `layout`, `page`, `route`, `default`, `generateMetadata`, `generateViewport`) and `searchParams` (in `page`) are Promises:
  `async function Page({ params }: { params: Promise<{ slug: string }> }) { const { slug } = await params }`
- `cookies()`, `headers()`, `draftMode()` return Promises: `const store = await cookies()`.
- In a Client Component, unwrap with `use(params)` from `react`.
- Sync access still works in 15 with warnings, but never write it — it is removed in 16.

## Caching is OFF by default
- `fetch` is not cached by default. Opt in with `{ cache: 'force-cache' }` or `{ next: { revalidate: <seconds> } }`.
- `GET` Route Handlers are not cached by default. Opt in with `export const dynamic = 'force-static'`. Metadata routes (`sitemap`, `icon`, `opengraph-image`) remain static by default.
- Client Router Cache: Page segments have `staleTime` 0 (always fresh on navigation); layouts and back/forward still reuse cache.
- `export const dynamic = 'force-dynamic'` also sets `no-store` on fetches.
- Calling `revalidateTag`/`revalidatePath` during render throws — call them in Server Actions or Route Handlers.

## Forms and Server Actions
- Form state: `useActionState` from `react` (replaces `useFormState`); `useFormStatus` from `react-dom`.
- `<Form>` from `next/form` for forms that navigate (e.g. search → results page).
- Unused Server Actions are removed at build and action IDs are unguessable — still validate and authorize inside every action.

## Config and APIs that changed from 14
- `experimental.serverComponentsExternalPackages` → `serverExternalPackages`.
- `experimental.bundlePagesExternals` → `bundlePagesRouterDependencies`.
- `experimental.swrDelta` → `expireTime`.
- `instrumentation.ts` is stable (`register`, `onRequestError`); remove `experimental.instrumentationHook`.
- `after()`: shipped as `unstable_after` from `next/server` behind `experimental.after` in 15.0 — check which name the installed version exports before using it.
- `next/dynamic` with `ssr: false` is not allowed in Server Components.
- `export const runtime = 'experimental-edge'` → `'edge'`.
- `middleware.ts` still the interception file.
- `next dev --turbo` (Turbopack dev) is stable; webpack remains the build default.
