# Next.js 16 (React 19.2)

Source: nextjs.org/blog/next-16 (16.0 release notes). Verified 2026-10-05. For APIs added in later 16.x minors, check `node_modules/next/*.d.ts`.

## Requirements
- Node.js ≥ 20.9, TypeScript ≥ 5.1.
- Browsers: Chrome/Edge/Firefox 111+, Safari 16.4+.

## Request APIs are async-only
- Sync access is removed. Always `await params`, `await searchParams`, `await cookies()`, `await headers()`, `await draftMode()`.
- Metadata image routes receive async `params`; the `id` from `generateImageMetadata` is `Promise<string>`.

## `proxy.ts` replaces `middleware.ts`
- New interception code: `proxy.ts` exporting `function proxy(request: NextRequest)`. It runs on the Node.js runtime.
- `middleware.ts` is deprecated and kept only for Edge runtime. If the project already has one, keep following it and flag the deprecation — migrate only when the task asks.

## Caching
- Caching is opt-in: dynamic code runs at request time by default.
- Cache Components: only when `next.config` has `cacheComponents: true`. Then use the `"use cache"` directive with `cacheLife` / `cacheTag`. Check the config before writing `"use cache"`.
- `experimental.dynamicIO` → `cacheComponents`. `experimental.ppr` and `export const experimental_ppr` are removed.
- `revalidateTag(tag, profile)` — the second argument is required (a `cacheLife` profile such as `'max'`, `'hours'`, `'days'`, or `{ expire: <seconds> }`). The single-argument form is deprecated.
- `updateTag(tag)` — Server Actions only; read-your-writes (expire and re-read in the same request).
- `refresh()` from `next/cache` — Server Actions only; refreshes uncached data without touching the cache.

## Build and tooling
- Turbopack is the default for `next dev` and `next build`. A custom webpack config needs `--webpack`.
- Turbopack config is top-level `turbopack` (not `experimental.turbopack`).
- `next lint` is removed and `next build` no longer lints — run ESLint or Biome directly. `@next/eslint-plugin-next` defaults to flat config.
- `reactCompiler: true` is a stable top-level option (off by default).
- Every parallel route slot needs an explicit `default.js` — the build fails without it.

## Removed
- AMP (`useAmp`, `config = { amp: true }`).
- `serverRuntimeConfig` / `publicRuntimeConfig` → use environment variables.
- `devIndicators` options `appIsrStatus`, `buildActivity`, `buildActivityPosition`.
- `unstable_rootParams()`.
- Automatic `scroll-behavior: smooth` → add `data-scroll-behavior="smooth"` on `<html>` to keep it.

## `next/image`
- Local `src` with a query string requires `images.localPatterns`.
- Use `images.remotePatterns`; `images.domains` and `next/legacy/image` are deprecated.
- New defaults: `minimumCacheTTL` 14400s, `qualities` `[75]` (the `quality` prop is coerced to the nearest allowed value), `16` removed from `imageSizes`, `maximumRedirects` 3, local IPs blocked unless `dangerouslyAllowLocalIP: true`.

## React 19.2 in the App Router
- Available: `<ViewTransition>`, `useEffectEvent`, `<Activity>`.
