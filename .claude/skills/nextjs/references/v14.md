# Next.js 14 (React 18)

Source: nextjs.org upgrade guide "version-14" and the 15 release notes (what 15 changed *from* 14). Verified 2026-10-05.

## Requirements
- Node.js ≥ 18.17.
- `next.config.js` / `next.config.mjs` only — `next.config.ts` is NOT supported (added in 15).

## Request APIs are synchronous
- `params` and `searchParams` are plain objects: `function Page({ params }: { params: { slug: string } })`.
- `cookies()`, `headers()`, `draftMode()` return values directly — do not `await` them or type them as `Promise`.

## Caching is ON by default
- `fetch` caches by default (`force-cache`). Opt out per request with `{ cache: 'no-store' }` or set `{ next: { revalidate: <seconds> } }`.
- `GET` Route Handlers are static by default unless they use a dynamic function (`cookies()`, `headers()`, …) or `export const dynamic = 'force-dynamic'`.
- The client Router Cache reuses visited pages; call `router.refresh()` or `revalidatePath`/`revalidateTag` after mutations.

## Forms and Server Actions
- Server Actions are stable (`'use server'`).
- Form state: `useFormState` and `useFormStatus` from `react-dom`. `useActionState` does NOT exist in React 18.

## Files and imports
- Request interception: `middleware.ts` (project root or `src/`), Edge runtime.
- `ImageResponse` is imported from `next/og` (not `next/server`).
- Fonts: built-in `next/font` (`@next/font` is removed).
- Static export: `output: 'export'` in config (`next export` command is removed).
- External server packages: `experimental.serverComponentsExternalPackages`.
- Linting: `next lint` is available.
